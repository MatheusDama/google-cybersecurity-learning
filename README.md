# Google Cybersecurity Professional Certificate — Learning Journey

Este repositório foi criado para documentar meu progresso, anotações e, principalmente, os laboratórios práticos desenvolvidos ao longo do **Google Cybersecurity Professional Certificate**, realizado em parceria com o **CIEE**.

O objetivo deste espaço é consolidar os conhecimentos adquiridos e servir como um portfólio técnico, demonstrando a aplicação prática de ferramentas essenciais para um Analista de Segurança da Informação (SOC).

---

## 🛠️ Habilidades Técnicas & Ferramentas Desenvolvidas

O programa cobre os fundamentos indispensáveis para a defesa cibernética através de módulos práticos:

* **Sistemas Operacionais & Redes:** Linha de comando Linux, gerenciamento de permissões de arquivos, análise de pacotes e protocolos de rede (TCP/IP, UDP, DNS, Wireshark).
* **Programação para Segurança:** Desenvolvimento de scripts em **Python** para automação de tarefas, leitura de logs e controle de listas de acesso.
* **Análise de Dados:** Consultas estruturadas em **SQL** para auditoria de bancos de dados e identificação de acessos ou modificações suspeitas.
* **Defesa Cibernética e Monitoramento:** Detecção de intrusões com **Suricata** (IDS) e análise/triagem de incidentes utilizando sistemas SIEM (**Chronicle** e **Splunk**).
* **Gestão de Incidentes & Riscos:** Aplicação prática dos frameworks do **NIST (CSF)**, análise de táticas de adversários pelo **MITRE ATT&CK** e elaboração de relatórios de incidentes.

---

## 📁 Estrutura do Repositório

*(Esta estrutura reflete os principais pilares práticos do certificado)*

* `/linux-and-networks` ➔ Práticas de comandos Linux, configuração de acessos e análise de rede.
* `/python-automation` ➔ Scripts em Python focados em automação de tarefas e segurança.
* `/sql-auditing` ➔ Consultas e scripts SQL para filtragem de dados e auditoria de segurança.
* `/siem-and-logs` ➔ Exercícios de análise de logs, alertas do Suricata e investigações em SIEM.
* `/incident-response` ➔ Relatórios de incidentes, playbooks e análises de casos de estudo.
